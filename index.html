I'm a cybersecurity-focused IT professional working toward a security operations role. I hold a B.S. in Information Technology from UNC Wilmington with a Cybersecurity concentration, and I work daily on endpoint diagnostics and remediation.

At Mr. Phix I triage inbound devices across iOS, Android, macOS, and Windows, remediate malware, and trace system failures to root cause. Much of that work is log analysis: filtering Windows Event Viewer across the System, Application, and Security channels to establish what failed and when.

My concentration coursework covered network security, information assurance, cryptography, ethical hacking, and Windows and Linux systems administration. Group work included a NIST SP 800-53 risk assessment of a federal system, analyzing 39 vulnerabilities to produce an Authorization to Operate recommendation.

Before IT, I spent five-plus years in client-facing roles across retail, golf operations, and county parks and recreation.

Outside of work I build custom desktop systems from component selection through OS deployment and maintain my own in-wall network infrastructure. I'm currently preparing for CompTIA Security+.

Core Competency

Windows Event Log Analysis & Root Cause Diagnosis

I use Windows Event Viewer as a primary diagnostic tool, filtering System, Application, and Security logs by event ID, severity level, and time window to isolate the origin of a failure rather than treating the symptom.

In practice that means correlating events across log channels to distinguish a failing drive from a corrupted driver, identifying failed service starts and unexpected shutdowns, tracing application crashes to a specific faulting module, and reviewing authentication and account events where compromise is suspected.

Formal grounding for this comes from my Windows Systems Administration coursework, which covered event logging and auditing for both performance and security.
